# 🏥 👨‍⚕️ OsteoLogica Medical Center Reviews Page

🌟 **Customer Reviews for the Osteopathy and Integrative Medicine Center OsteoLogica**, led by Dr. Polyakov in Samara, Russia.

## Overview

📝 This project showcases a dedicated webpage for reviews of the OsteoLogica Center and its healthcare professionals. It provides essential information about the doctors, contact details, and a convenient feedback submission form. To explore the full site, visit [https://osteologika.ru](https://osteologika.ru).

## Key Features

-   🚦 **Form Validation:** The feedback form is equipped with client-side validation to ensure all mandatory fields are completed correctly. Email addresses are validated using regular expressions for accuracy.

-   📧 **Feedback Submission:** User feedback is securely sent to the clinic's email address through a PHP script (`sendmail.php`), streamlining the email delivery process.

## Technologies Utilized

-   🖼️ **HTML5 & CSS3:** Used for structuring and designing the webpage with modern web standards.

-   🛠️ **JavaScript:** Adds interactivity, including form validation, smooth scrolling, and toggle functionality for the navigation menu.

-   📬 **PHP:** Manages form submissions and handles the secure transmission of feedback to the clinic's email.

-   📱 **Responsive Design:** Ensures an optimal viewing experience across a wide range of devices, from desktops to mobile phones.

# Страница отзывов Центра ОстеоЛогика

🌟 Отзывы клиентов о Центре остеопатии и интегративной медицины ОстеоЛогика, возглавляемом доктором Поляковым в Самаре, Россия.

## Обзор

📝 Этот проект представляет собой специализированную веб-страницу для отзывов о Центре ОстеоЛогика и его медицинских работниках. Она содержит важную информацию о врачах, контактные данные и удобную форму для отправки отзывов. Чтобы ознакомиться с полным сайтом, посетите [osteologika.ru](https://osteologika.ru).

## Ключевые особенности

- 🚦 **Валидация формы**: Форма обратной связи оснащена клиентской валидацией, чтобы гарантировать, что все обязательные поля заполнены корректно. Адреса электронной почты проверяются с помощью регулярных выражений на точность.

- 📧 **Отправка отзывов**: Отзывы пользователей безопасно отправляются на электронную почту клиники через PHP-скрипт (sendmail.php), упрощая процесс доставки электронной почты.

## Используемые технологии

- 🖼️ **HTML5 и CSS3**: Используются для структурирования и оформления веб-страницы в соответствии с современными веб-стандартами.

- 🛠️ **JavaScript**: Добавляет интерактивность, включая валидацию формы, плавный скроллинг и функциональность переключения для навигационного меню.

- 📬 **PHP**: Управляет отправкой форм и обеспечивает безопасную передачу отзывов на электронную почту клиники.

- 📱 **Адаптивный дизайн**: Обеспечивает оптимальный просмотр на различных устройствах, от настольных компьютеров до мобильных телефонов.
